# Skill: 双足机器人传感器标定

## 适用范围

双足人形机器人。

## 双足的标定特殊性

### 1. 标定相互依赖

双足平衡控制对**多个传感器协同精度**敏感。一个不准就会拖垮整体:

- IMU 不准 → 平衡控制器误判,关节力矩输出错
- 足力不准 → 接触判断错,支撑/摆动腿误判
- 关节零位不准 → 运动学计算错,质心估计错

实际意义:**双足必须做完整套标定**(IMU + 足力 + 关节),不能只做一个。

### 2. 标定的"金标准姿态"

双足通常用**标准站立姿态**作为标定参考:
- 双脚并拢或微宽于肩
- 身体直立,关节零位
- 重心居中
- 完全静止

任何标定都从这个姿态开始,产出稳定的零基准。

### 3. 摔倒后必须重新标定

参考 humanoid/joint-thermal-management,摔倒会:
- 改变 IMU 安装(轻微偏移)
- 让足力传感器零点漂移
- 可能撞松关节零位标记

每次摔倒后**强制做完整标定**,不要只看"看起来正常"。

## 双足扩展 universal 框架

### 前置条件:站姿要求

universal 说"前置条件最关键",双足的特殊前置条件:
- **绝对水平地面**(用水平仪验证)
- 标准站姿(参考第 2 节)
- 静止 5 秒以上(让 IMU 输出稳定)
- 上电预热完成(IMU 温漂稳定,> 2 分钟)

### 验证流程:三测试法

universal 说"必须验证",双足的标定验证有三个标准测试:

| 测试 | 目的 | 通过标准 |
|---|---|---|
| 静止站立 60s | 验证零偏 + 平衡 | 角度漂移 < 1° |
| 原地踏步 10 步 | 验证步态稳定 | 无失稳警告 |
| 转向 360° | 验证方向积分 | 朝向误差 < 5° |

只有三个测试都通过,才算标定成功。

## 双足标定周期

| 场景 | 周期 |
|---|---|
| 日常运行 | 每周检查标定状态 |
| 定期维护 | 每月完整标定 |
| 长途运输后 | 使用前必标 |
| 摔倒/碰撞后 | 立即检查 + 标定 |
| 更换传感器后 | 立即标定 |
| 季节交替(温度变化大) | 重做 IMU 标定 |
