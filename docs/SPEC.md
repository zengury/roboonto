# RoboOnto 规范索引

RoboOnto 0.9 的规范来源是：

1. [PackModule 0.9 语义规范](PACKMODULE_0.9_SPEC.md)；
2. `roboonto/pack/model.py` 的类型化 AST；
3. `roboonto/pack/packmodule.schema.json` 的序列化 Schema；
4. [RoboOnto 3.0 集成契约](ROBOONTO3_INTEGRATION.md)。

旧 `roboonto/core/meta-schema.yaml`、`includes` 分片和自由 `properties` 仅属于
0.4 compatibility/migration source，不再是 0.9 的规范语言层。
